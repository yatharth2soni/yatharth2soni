# Setup: Yatharth's GitHub profile README

## What's included

- `README.md` — Figma-inspired black-and-white terminal profile. The only subtitle beneath the name is **BTech CSE student**. The visible profile emphasizes projects, open-source contributions, and DSA/problem-solving practice.
- `assets/profile-intro.gif` — a full-profile circular reveal: a tiny white circle grows with a bright white boundary and reveals a compact dashboard containing the name, role, project cards, current public PR statuses, and DSA focus. The latest PR status/counts are regenerated by GitHub Actions.
- `assets/terminal-footer.svg` — matching terminal-style end marker.
- `assets/contribution-graph.svg`, `assets/contribution-pie.svg`, `assets/github-stats.svg`, `assets/language-stats.svg` — locally hosted SVG charts, generated by the workflow so the README doesn't depend on third-party chart-image services. The multicolor pie shows the most recently updated public PRs grouped by upstream repository.
- `scripts/profile_intro.py` — renders the animated circle-reveal GIF using Pillow.
- `scripts/sync_profile.py` — fetches public GitHub repository and PR data, filters excluded coding-platform repository names from the profile display, refreshes the README section between markers, and regenerates local chart/intro assets.
- `.github/workflows/profile-sync.yml` — runs on demand and hourly.
- `preview.html` — interactive browser mockup with a viewport-wide circle reveal overlay. This effect runs on a webpage, not inside GitHub Markdown.

## Publish it

1. Make sure a **public profile repository named exactly `yatharth2soni`** exists. The repository list available when this package was prepared did not include `yatharth2soni/yatharth2soni`, so create it if it doesn't exist yet.
2. Extract the ZIP and upload the **contents** of the package (not the enclosing folder) to the root of that repository. Keep `.github/workflows/`, `scripts/`, and `assets/` in the shown locations.
3. Open the repository's **Settings → Actions → General** and ensure Actions are allowed. Under workflow permissions, allow read/write repository contents so Actions can commit generated updates.
4. Open **Actions → Sync GitHub profile README → Run workflow** and run it once. The workflow installs Pillow, refreshes the SVG assets and intro GIF, and updates the data tables.
5. Refresh your profile after the workflow completes. The contribution graph is based on GitHub's contribution calendar, not an invented or randomized heatmap.

## What updates automatically

The workflow checks hourly. It refreshes the public repository table, public PR status table, multicolor PR contribution pie, stats chart, language chart, contribution calendar, and opening GIF. It commits only if the generated files change. A project that exists only on your laptop won't appear until you push it to GitHub.

## Important GitHub animation limitation

GitHub sanitizes profile README content; arbitrary page-wide JavaScript/CSS overlays cannot run in Markdown. The self-hosted GIF therefore provides the circle-growing animation at the top and finishes on a readable summary of the profile. The clickable, full details are live Markdown below it. `preview.html` demonstrates what a true viewport-wide overlay looks like on a normal webpage; it is not executed by GitHub as part of the README.

## If charts show a setup message

The included SVG files are valid local images and display an explicit setup state, not a broken-image icon. Run the Actions workflow once to replace the contribution graph placeholder with the current calendar and refresh the language/stats cards. The local assets must be uploaded along with `README.md`; uploading only the Markdown file will make `assets/...` paths fail.
