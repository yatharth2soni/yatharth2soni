# Setup: Yatharth's GitHub profile README

## What's included

- `README.md` — Figma-inspired black-and-white terminal profile. The only subtitle beneath the name is **BTech CSE student**. It keeps the projects, open-source contributions, DSA practice focus, clickable links, and charts in normal Markdown.
- `assets/profile-intro.gif` — a **compact header-only** circle-reveal animation. It grows from a tiny white circle into a bright outlined terminal banner; it does not contain the entire profile or any project/PR links.
- `assets/terminal-footer.svg` — matching terminal-style end marker.
- `assets/contribution-graph.svg`, `assets/contribution-pie.svg`, `assets/github-stats.svg`, `assets/language-stats.svg` — local SVG charts generated by the workflow.
- `scripts/profile_intro.py` — creates the compact intro GIF using Pillow.
- `scripts/sync_profile.py` — refreshes public repository and pull-request data and regenerates the charts and intro asset.
- `.github/workflows/profile-sync.yml` — runs on demand and hourly.
- `preview.html` — standalone browser preview of the readable layout. Links and sections are actual clickable page content.

## Publish it

1. Make sure your public profile repository is named exactly `yatharth2soni` (repository URL: `https://github.com/yatharth2soni/yatharth2soni`).
2. Extract the ZIP and upload the **contents** of the package to the repository root. Keep `.github/workflows/`, `scripts/`, and `assets/` in the shown locations.
3. Open **Settings → Actions → General**, make sure Actions are allowed, and enable read/write repository contents for the workflow.
4. Open **Actions → Sync GitHub profile README → Run workflow** to run it once.
5. Refresh your profile after the workflow finishes.

## What updates automatically

The workflow checks hourly and refreshes public repository/PR tables, the multicolour PR pie chart, stats, language chart, public contribution calendar, and compact intro GIF. It commits only when generated files change. Work only on your laptop does not appear until pushed to GitHub.

## Why the profile now looks different

A README GIF is a single image, so text inside it cannot be selected or links inside it clicked. The previous animation put the entire dashboard inside a giant circle, which made the text tiny and hid the real README sections below the fold. This version animates **only a 960×340 header**. Projects, PRs, stats, and profile links remain normal, readable, clickable Markdown underneath.

GitHub does not allow a README to run page-wide JavaScript/CSS to hide the entire profile until the animation finishes. The circle animation is therefore confined to the banner, which is the most reliable GitHub-compatible approach.
